# 🎓 Student Registration Form

A simple **Student Registration Form** created using **HTML**.  
This project demonstrates the use of HTML form elements such as text fields, email fields, password fields, radio buttons, checkboxes, date input, and a submit button.

---

## 📌 Project Overview

The Student Registration Form allows users to enter their basic details and register as a student.

### The form includes:

- 👤 Full Name
- 📧 Email
- 🔐 Password
- ⚧️ Gender
- 💻 Skills
- 🎂 Date of Birth
- 📝 Register Button

---

## 🛠️ Technologies Used

- **HTML5**
- **Semantic HTML**
- **HTML Form Elements**
- **HTML Tables**
